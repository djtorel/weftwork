# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues, pull requests and discussions, and
anywhere you represent the project.

In short: be respectful, assume good faith, give and accept feedback on the
work and not the person, and do not harass anyone.

## Reporting

Report unacceptable behaviour privately to the maintainer through the
contact on the maintainer's GitHub profile
(<https://github.com/djtorel>). Reports are kept confidential. The
maintainer acts on the Covenant's enforcement guidelines: correction,
warning, temporary ban or permanent ban.
